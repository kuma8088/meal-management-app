# Part 1: LINE チャットでのテスト

## 事前準備

### LINE Bot 友だち追加

1. [LINE Developers コンソール](https://developers.line.biz/console/) にログイン
2. 対象のチャネル → 「Messaging API設定」→ 「QRコード」を取得
3. LINE アプリで QR コードをスキャンして友だち追加

---

## L0. 自動ユーザー登録

LINE ユーザーが**初めてメッセージを送信した際**、自動的にシステムにユーザー登録されます。

| # | 手順 | 期待結果 |
|---|------|---------|
| 1 | LINE Bot に任意のメッセージを送信（初回） | ユーザーが自動登録される |
| 2 | DynamoDB の Users テーブルを確認 | 新しいエントリが作成されている |

**自動作成されるデータ:**
```json
{
  "user_id": "uuid（自動生成）",
  "line_user_id": "LINE User ID",
  "tdee": 2000.0,
  "bmr": 1500.0,
  "source": "line",
  "created_at": "ISO8601形式"
}
```

**確認コマンド:**
```bash
aws dynamodb scan --table-name meal-management-app-users-dev \
  --filter-expression "source = :source" \
  --expression-attribute-values '{":source": {"S": "line"}}'
```

**注意事項:**
- 友だち追加だけではユーザー登録されない（メッセージ送信が必要）
- プロフィール（身長・体重・活動量）は LINE からは設定できない
- TDEE/BMR はデフォルト値を使用。個人最適化は Web アプリから設定

## L3. 食事登録（テキスト形式）

### 入力形式

| 形式 | 例 | 説明 |
|------|-----|------|
| 食品名 + 量 | `ご飯 150g` | 食事タイプは snack（間食）として登録 |
| 食事タイプ + 食品名 + 量 | `朝食 白米 200g` | 指定した食事タイプで登録 |

### 対応する食事タイプキーワード

| キーワード | 登録される食事タイプ |
|------------|---------------------|
| 朝食, 朝 | breakfast |
| 昼食, 昼 | lunch |
| 夕食, 夕, 夜 | dinner |
| おやつ, 間食 | snack |
| (指定なし) | snack |

### 対応する量の単位

| 単位 | 例 |
|------|-----|
| g | 150g |
| グラム | 150グラム |
| ml | 200ml |
| ミリリットル | 200ミリリットル |

### テスト手順

| # | 手順 | 期待結果 |
|---|------|---------|
| 1 | 「ご飯 150g」と送信 | 食事登録成功メッセージ |
| 2 | 「朝食 白米 200g」と送信 | 朝食として登録成功 |
| 3 | 「昼食 サラダ 100g」と送信 | 昼食として登録成功 |
| 4 | 「ほげほげ 100g」と送信 | 食品未発見メッセージ |

**期待される返信（成功時）:**
```
✅ 食事を登録しました！

【朝食】白米 150g

カロリー: 252 kcal
たんぱく質: 3.9 g
脂質: 0.5 g
炭水化物: 55.7 g
```

**期待される返信（食品未発見時）:**
```
「ほげほげ」に該当する食品が見つかりませんでした。別の名前で試してください。
```

**期待される返信（形式エラー時）:**
```
食事登録の形式が認識できませんでした。

以下の形式で送信してください：
「ご飯 150g」
「朝食 白米 200g」
「昼食 サラダ100g」

または、食品のバーコード画像を送信してください。
```

### 制限事項

- 1メッセージ1食品のみ対応（複数食品は別々に送信）
- 検索結果の最初の1件を自動使用（候補選択機能なし）

