# ユーザテスト手順書

## 概要

食事管理アプリケーションの手動テスト手順です。

## テスト環境

- **フロントエンド**: http://localhost:5173（開発）
- **API**: https://868t2tljy9.execute-api.ap-northeast-1.amazonaws.com/dev
- **テストユーザー**: 新規作成または e2e-test@example.com

## 事前準備

```bash
# フロントエンド起動
cd frontend && npm run dev
```

## 1. ユーザー登録・ログイン

### 1.1 新規ユーザー登録

| # | 手順 | 期待結果 |
|---|------|---------|
| 1 | http://localhost:5173/login にアクセス | ログイン画面表示 |
| 2 | 「ユーザー登録」タブをクリック | 登録フォーム表示 |
| 3 | メールアドレス・パスワード入力 | 入力可能 |
| 4 | 「登録」ボタンをクリック | 確認コード入力画面へ遷移 |
| 5 | メールの確認コードを入力 | ログイン成功 |

### 1.2 ログイン

| # | 手順 | 期待結果 |

| 1 | メールアドレス・パスワード入力 | 入力可能 |
